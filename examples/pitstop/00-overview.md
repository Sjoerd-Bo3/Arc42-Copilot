# Pitstop - Architecture Documentation

> **Pitstop** is a fictitious garage management system used as a reference example for arc42 documentation.
> Based on the [Pitstop example](https://gist.github.com/eNeRGy164/90f63e78d3e528f7b8490538a6781b5f) by Michael Hompus.

Pitstop is the garage's operational brain: it synchronizes planning, creates/updates work orders, and keeps the admin overview and workshop view consistent in near real-time.
